# Docs

This folder holds the guides that were sections of the old README, plus the gap report and the STRIDE review. [history.md](history.md#old-to-new-section-map) maps each old README section to its new place.

- [architecture.md](architecture.md): how the agent, a question and a write work, the skills, the agent commands, the repo layout and the MCP tools (old README 1, 2, the agent part of 9, 13 and Appendix B).
- [harness.md](harness.md): the harness, its 22 tasks, verifiers, scoring, calibration and run files, and the harness commands (old README 3 and the harness part of 9).
- [gap-to-code.md](gap-to-code.md): each point of the gap report, the features A1–A14, the platform requests P1–P13 and the roadmap (old README 4).
- [background.md](background.md): the platform, the 23 Sept data change, the graded scenario, the benchmarks, the research and the id cheat sheet (old README 5 to 5.5 and Appendix A).
- [bugs.md](bugs.md): the bugs raised (old README 5.6).
- [plan-and-status.md](plan-and-status.md): the old status lines and Tests section, the Step 4 plan, the results so far and the files you own (old README front matter, Tests, 6, 10 and 12).
- [checking.md](checking.md): how to check each part by hand (old README 7 to 7.5).
- [live-run.md](live-run.md): the single live write run, before, during and after (old README 7.6, 11 and the paragraph *Before the live write run*).
- [safety.md](safety.md): the STRIDE behaviour changes, the ground rules and the safety rules 1–13 (old README Security review, the ground rules of 6.1, and 8).
- [known-limits.md](known-limits.md): known limits and open questions (old README 14).
- [history.md](history.md): the review rounds, the old Contents, Quick start and The idea in one minute, and the old-to-new section map (old README 15).
- [troubleshooting.md](troubleshooting.md): error messages and what to do (old README 16).
- [gap_report.md](gap_report.md): the one-page gap report (Step 3, updated 27 Sept).
- [security/stride-review.md](security/stride-review.md): the full STRIDE security review and its fixes.
